# Session log — 2026-09-23

Branch: `claude/cool-brown-7z0clo`

## Goal

Build the first playable version of the game from an empty repo (it only had
a LICENSE). The brief:

- a lobby of up to 10 players
- players race to be first to park on a trailer that drives around the track
- rivals ram each other, and cars that take enough damage are destroyed, with
  the driver spectating
- a pick of 5 derby cars with identical speed and handling
- drifting
- parking hard enough that a match lasts a few minutes

## Notable problems found and fixed during the session

- **Track hairpin too tight.** The first control points gave a 32-stud
  minimum turn radius, and the rigid ~80-stud truck would have swung its cab
  about 30 studs off the road. A Python check of spline radius and
  self-separation was used to pick a lobed-ellipse layout: minimum radius
  about 95 studs, about 10 studs of overhang, and at least 186 studs between
  non-adjacent sections. See ADR-0004.
- **Parking judged against lagged positions.** The first version judged
  parking only from the server's view. Because the car is client-owned and
  the truck server-owned, the server sees the car about speed × latency
  (about 9 studs) behind its real spot on the deck. Replaced with a
  client-reported, bay-relative pose that the server sanity-checks. See
  ADR-0006.
- **Camera re-snapping every frame.** `CameraController.Follow` reset its
  smoothing on every call. It now only resets when the subject changes.
- **Undefined helper call.** `CarBuilder` used `addNumberAndBars` before it
  was defined as a local. The function was moved above its callers.
- **Walls grouped with drivable ground.** The arena walls were in the same
  folder as the ground surface. Walls got their own folder so the damage
  contact check (which excludes the surface folder) still counts wall hits.
- **Tuning corrections:**
  - suspension stiffness raised to 220 so the car sags about 0.9 studs at rest
  - bay enlarged to 10×17
  - ramp lip raised to 0.9 so it doesn't scrape when the truck rolls
